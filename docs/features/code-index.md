# コードインデックス

ソースを分割して埋め込みベクトルにし、意味による検索を LLM へ提供する仕組みである。
**既定では無効であり、有効にするまで外部へ通信しない。**

## 目的

| 満たす要件                          | 内容                                                              |
| ----------------------------------- | ----------------------------------------------------------------- |
| `FR-IDX-01` `FR-IDX-02` `FR-IDX-03` | 意味による検索を提供する。埋め込みは OpenAI 互換、保存先は Qdrant |
| `FR-IDX-04` `FR-IDX-05`             | 検索の件数とスコアの下限、埋め込みを求める 1 回あたりの件数       |
| `FR-IDX-06`                         | 既定で無効とする                                                  |
| `FR-IDX-07` `FR-IDX-07a`            | 構造の解析に対応する言語の範囲                                    |

ユースケースは UC-05（コードベースを探索させる）。

### 扱わないもの

| 対象                                 | どこにあるか                     |
| ------------------------------------ | -------------------------------- |
| 正規表現による検索                   | [file-access.md](file-access.md) |
| `codebase_search` を提示するかどうか | [tools.md](tools.md)             |

## 決めごと

実装は `src/services/code-index/`。埋め込みの実装は OpenAI 互換の 1 つだけで、
ベクトルの保存先は Qdrant の 1 つだけである。

### 対応する言語は、解析の対象を決めるだけ

構造の解析（定義の抽出と索引）に対応する言語の一覧は `README.md` にある。一覧に無い
言語は解析されないだけで、読み取りと編集の対象からは外れない。

一覧を増やすときは、`packages/build` のビルド設定へ言語を足す。

### 既定で無効とする

有効にすると、埋め込みの接続先と Qdrant の 2 つが通信先へ加わる。既定の通信先を
1 本に保つため（[network.md](network.md)）、有効化は利用者の操作に限る。

## 制約

- 埋め込みの接続先と Qdrant の双方を、利用者が用意する。
- ベクトルは外部のベクトルストアへ置き、本製品の内側には持たない。
- 検索の件数とスコアの下限には、それぞれ範囲の制限がある。

## 危険なところ

- 有効にしたことを利用者が忘れると、通信先が増えたままになる。設定の画面で
  現在の状態を確かめられるようにしておく。
- 索引の対象はワークスペース全体である。`.agentignore` の除外との関係を確かめる。

## 確かめ方

| 何を                 | どこで                                                        |
| -------------------- | ------------------------------------------------------------- |
| 検索の動作           | `src/core/tools/__tests__/codebaseSearchTool.spec.ts`         |
| 設定の受け渡し       | `src/core/webview/__tests__/codeIndexMessageHandlers.spec.ts` |
| 既定で無効であること | `packages/types/src/codebase-index.ts` を読む                 |

## できていないこと

- 使うかどうかを決めていない（`requirements.md` の 5.2）。Qdrant と埋め込みの接続先を
  用意するかどうかの判断が要る。
- 索引と `.agentignore` の関係を確かめていない（`FR-IDX-01`）。
