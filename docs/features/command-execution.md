# コマンドの実行

LLM がターミナルでコマンドを実行し、その出力を受け取る経路である。ファイルの編集と
並んで、外部へ影響を及ぼす 2 つの操作の 1 つである。

## 目的

| 満たす要件                            | 内容                                                             |
| ------------------------------------- | ---------------------------------------------------------------- |
| `FR-CMD-01` `FR-CMD-02`               | コマンドを実行し、出力を受け取る。実行中の出力を後から追加で読む |
| `FR-CMD-03` `FR-CMD-03a` `FR-CMD-03b` | シェル統合による出力と終了コードの取得。使わない経路への切り替え |
| `FR-CMD-04` `FR-CMD-04a`              | 実行の上限の時間と、それを適用しないコマンドの指定               |
| `FR-CMD-05` `FR-CMD-06`               | 出力の表示量の上限と、使うシェルの指定                           |
| `FR-CMD-07`                           | 利用者がターミナルのコマンドを選んで説明または修正を依頼する     |

ユースケースは UC-06（コマンドを実行させ、出力を読ませる）。

### 扱わないもの

| 対象                       | どこにあるか                     |
| -------------------------- | -------------------------------- |
| 実行してよいコマンドの判定 | [approval.md](approval.md)       |
| コマンドの引数のパスの検査 | [file-access.md](file-access.md) |

## 方式

実装は `src/core/tools/ExecuteCommandTool.ts` と `src/integrations/terminal/`。

### 出力と終了コードはシェル統合から取る

VS Code のシェル統合を使うと、コマンドの開始と終了、および終了コードを取得できる。
統合が効かない環境のために、統合を使わない実行へ切り替える設定を持つ。

シェル統合の待機と、コマンドを発行するまでの遅延は、いずれも設定で変えられる。
どちらも環境ごとの差を吸収するためにある。

### 上限の時間には例外の一覧を持つ

ビルドや長いテストは上限を超える。コマンドの前方一致で上限を適用しない一覧を持ち、
利用者が指定する。

### 出力は先頭と末尾を残す

出力の全量を LLM へ返すと、1 回のコマンドでコンテキストウィンドウが埋まる。表示量の
上限は利用者が選ぶ。追加の出力が要るときは、専用のツールで読み直す。

## 制約

- 終了コードは、シェル統合が効く環境でのみ確実に取れる。
- 上限の時間の既定は 0 であり、上限を設けないことを表す。
- コマンドの実行は、ワークスペースのディレクトリを起点とする。

## 危険なところ

- **実行するコマンドは、LLM が組み立てた文字列である。** 読み込んだファイルの中身が
  そのまま指示として働くことがある。承認の判定は [approval.md](approval.md) が持つ。
- 上限を適用しない一覧は前方一致である。短い接頭辞を書くと、意図しないコマンドまで
  上限の外へ出る。

## 確かめ方

| 何を                                | どこで                                                             |
| ----------------------------------- | ------------------------------------------------------------------ |
| 実行と出力の取得                    | `src/integrations/terminal/__tests__/TerminalProcess.spec.ts`      |
| シェル統合を使わない経路            | `src/integrations/terminal/__tests__/ExecaTerminalProcess.spec.ts` |
| 出力が会話へ戻ること                | `apps/vscode-e2e/src/suite/tool-effects.test.ts`                   |
| 非ゼロの終了コードが LLM へ戻ること | `apps/vscode-e2e/src/suite/failure-paths.test.ts`                  |

## できていないこと

- 対話を求めるコマンド（入力を待つもの）へ応答する手段が無い（`FR-CMD-01`）。
- Windows での動作を確かめる手段が無い（`requirements.md` の 5.2）。
