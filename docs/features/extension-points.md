# 拡張ポイント（ルール・スキル・スラッシュコマンド）

利用者が、コードを変えずに指示を足せる場所である。3 つあり、いずれもプロジェクトと
利用者のホームの双方から読み込む。

## 目的

| 満たす要件                                         | 内容                                       |
| -------------------------------------------------- | ------------------------------------------ |
| `FR-EXT-01` `FR-EXT-01a`                           | 規則のファイルをシステムプロンプトへ加える |
| `FR-EXT-02` `FR-EXT-02a` `FR-EXT-02b` `FR-EXT-02c` | スキルの探索と、名前およびモードの制約     |
| `FR-EXT-03` `FR-EXT-03a` `FR-EXT-03b`              | スラッシュコマンドと、探索の範囲の制限     |
| `FR-EXT-04`                                        | 実験的な機能の個別の有効化                 |

ユースケースは UC-19（プロジェクト固有の指示を与える）。

### 扱わないもの

| 対象                                              | どこにあるか         |
| ------------------------------------------------- | -------------------- |
| `run_slash_command` と `skill` を提示するかどうか | [tools.md](tools.md) |
| モードごとの接尾辞の付け方                        | [modes.md](modes.md) |

## 決めごと

実装は `src/services/agent-config/`（規則）・`src/services/skills/`（スキル）・
`src/services/command/`（スラッシュコマンド）。

### 3 つの違い

|                    | いつ読み込むか | LLM から見た形           |
| ------------------ | -------------- | ------------------------ |
| 規則               | 毎回           | システムプロンプトの一部 |
| スキル             | 呼び出したとき | ツールの結果             |
| スラッシュコマンド | 呼び出したとき | ツールの結果             |

規則は毎回のリクエストへ入るので、量が直接コストになる。手順を書くならスキルへ置く。

### 探索の範囲から出さない

スラッシュコマンドの探索では、相対パスによる範囲の逸脱とシンボリックリンクを拒否する。
拒否しないと、ワークスペースの外のファイルを読み込ませられる。

### スキルの名前は外部の仕様に合わせる

名前の文字と長さの制約は agentskills.io の仕様に従う。ほかのツールが置いたスキルを
そのまま読めるようにするためである。

スキルは利用できる役割モードを指定できる。指定が無い場合はすべてのモードで使える。

## 制約

- 組み込みのスキルは持たない。仕組みだけを持つ。
- 組み込みのスラッシュコマンドは 1 件だけである。
- スラッシュコマンドを LLM から呼べるのは、実験的な機能を有効にした場合に限る。

## 危険なところ

- **規則のファイルを長くすると、毎回のリクエストが重くなる。** 量の上限を持たない。
- 探索の範囲の検査を外すと、ワークスペースの外を読める。新しい探索の経路を足すときは、
  同じ検査にかける。

## 確かめ方

| 何を                     | どこで                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| 範囲の逸脱とリンクの拒否 | `src/services/command/__tests__/commands.pathTraversal.spec.ts`、`symlink-commands.spec.ts` |
| スキルの探索と名前の検証 | `src/services/skills/__tests__/SkillsManager.spec.ts`                                       |
| 規則の読み込み           | `src/core/prompts/sections/__tests__/custom-instructions.spec.ts`                           |

## できていないこと

- 実際にスキルを定義して使うかどうかを決めていない（`requirements.md` の 5.2）。
- 実験的な機能を既定で有効にするかどうかを決めていない（同上）。
