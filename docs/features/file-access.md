# ファイルの読み取りと探索

LLM がワークスペースの中身を知るための経路である。読み取り・一覧・検索の 3 つと、
利用者が明示的に渡す経路（`@` による指定、選択範囲の追加）からなる。

## 目的

| 満たす要件                                             | 内容                                                                |
| ------------------------------------------------------ | ------------------------------------------------------------------- |
| `FR-FILE-01` `FR-FILE-01a` `FR-FILE-02` `FR-FILE-03`   | ファイルを読み、一覧を取り、正規表現で検索する                      |
| `FR-FILE-04`                                           | 利用者が `@` でファイル・フォルダ・診断・ターミナルの出力を指定する |
| `FR-FILE-05` `FR-FILE-05a`                             | 画像を送信内容へ含める。大きさに上限を設ける                        |
| `FR-FILE-06` `FR-FILE-07`                              | エディタとターミナルの選択範囲を、コンテキストへ足す                |
| `FR-FILE-50` `FR-FILE-50a` `FR-FILE-50b` `FR-FILE-50c` | `.agentignore` による除外                                           |
| `NFR-SEC-05`                                           | 秘密情報を含むファイルを、送信内容から外す手段を利用者へ与える      |

ユースケースは UC-05（コードベースを探索させる）。

## 決めごと

検索は VS Code に同梱される ripgrep を使う。構造の解析は tree-sitter による
（対応する言語は `README.md` に一覧がある）。

### 除外は 1 か所で判定し、すべての経路から呼ぶ

`src/core/ignore/AgentIgnoreController.ts` がワークスペース直下の `.agentignore` を
`.gitignore` と同じ書式で読み、パスの可否を返す。読み取り・編集・検索の各ツールが
最初にこれを呼ぶ。

**経路ごとに確かめる。** 1 つの経路で除外されることを確かめても、ほかの経路が
抜けていることがある。

シンボリックリンクは実体のパスへ解決してから判定する。解決しないと、ワークスペースの
外を指すリンクを置くだけで除外を回避できる。ファイルの中身を読むシェルコマンド
（`cat` や `grep` など）は、引数のパスを同じ判定にかける。

`.agentignore` が無い場合は、すべてを許可する。

## 制約

- 除外はワークスペース直下の 1 ファイルだけを読む。サブディレクトリごとの指定は持たない。
- 画像の大きさの上限は、1 枚あたりと合計の 2 つを持つ。超えた画像は送信内容へ入れない。
- 読み取りの結果に行番号を添えるのは、編集ツールが行番号で位置を指すためである。

## 危険なところ

- **除外の判定を通さない経路を足すと、その経路だけが穴になる。** 新しくファイルを
  読むツールを足すときは、最初に `validateAccess` を呼ぶ。
- シェルコマンドの引数の検査は、コマンドの種類の一覧に依存する。一覧に無いコマンドで
  ファイルを読めば、検査の対象にならない。

## 確かめ方

| 何を                                     | どこで                                                             |
| ---------------------------------------- | ------------------------------------------------------------------ |
| 除外が各経路で効くこと                   | `src/core/ignore/__tests__/AgentIgnoreController.spec.ts`          |
| リンクとコマンドの引数での回避を拒むこと | `src/core/ignore/__tests__/AgentIgnoreController.security.spec.ts` |
| 読み取り・一覧・検索の動作               | `src/core/tools/__tests__/readFileTool.spec.ts` ほか               |

## できていないこと

- 除外されたファイルの存在そのものは、一覧の設定によっては見える（`FR-FILE-50c`）。
- サブディレクトリごとの `.agentignore` に対応しない（`FR-FILE-50`）。
